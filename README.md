# SAFE WAY · 재외국민 안전지원

전쟁·재난 상황에서 해외 체류 중인 대한민국 국민이 위치와 상황을 알리고, 검증된 대피 정보를 바탕으로 대피 경로를 확인하는 웹앱 프로토타입입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 위치 기능은 HTTPS 또는 `localhost` 환경에서 가장 안정적으로 동작합니다.

예를 들어 Node.js가 설치되어 있다면 프로젝트 폴더에서 아래를 실행한 뒤 브라우저로 `http://localhost:8080`을 여세요.

```sh
npx serve .
```

## 현재 구현 범위

- 홈의 긴급 구조 요청 버튼과 24시간 영사콜센터 전화 연결
- 이스라엘·이란 전용 국가 검색/선택과 국가별 지도·임시 집결지 안내
- 현재 확인된 위치에 맞춘 대피 공지와 지정 대피 장소 카드 표시
- 브라우저 Geolocation API로 현재 위치 확인 (권한 거부 시 명확한 데모 위치 처리)
- 대피 필요·의료 지원·안전 확인 상황 선택 및 추가 설명 입력
- 구조 요청 완료 피드백과 지도 기반 권장 이동 경로
- 공식 확인 정보임을 구별하는 UI 구조 및 최종 확인 시각 표시

## 실제 운영 연동 전 필수 작업

현재 구조 요청 전송과 대피소 데이터는 UI 시연용입니다. 운영 환경에서는 `app.js`의 `sendButton` 클릭 처리에 인증된 서버 API를 연결하고, 서버에서 다음을 수행해야 합니다.

1. 사용자의 동의, 신고 내용, 좌표를 암호화해 외교부의 승인된 접수 API로 전달
2. 국가·도시별 외교부 검증 대피소, 통행 제한 및 여행경보 데이터를 서버에서 수집·서명 검증
3. 최신 통행 가능 도로를 반영한 라우팅 서비스로 경로 생성
4. 재전송, 접수번호, 담당자 상태, 다국어·접근성 및 개인정보 보존 정책 적용

클라이언트에 외교부 API 키나 민감한 접수 정보를 두지 마세요.
